# Homebrew Tap

Homebrew tap for [githendrik](https://github.com/githendrik)'s tools.

```bash
brew tap githendrik/tap
```

## Available

| Tool | Install | Description |
|---|---|---|
| [kiro-proxy](https://github.com/githendrik/kiro-proxy-go) | `brew install githendrik/tap/kiro-proxy` | OpenAI-compatible proxy for Kiro |
| [secret-proxy](https://github.com/githendrik/secret-proxy-go) | `brew install githendrik/tap/secret-proxy` | Local MITM proxy that swaps dummy placeholders for real secrets |

`secret-proxy` is shipped as a **Cask** (macOS only). Linux builds are attached
to each [GitHub release](https://github.com/githendrik/secret-proxy-go/releases),
or use `go install`.

## Note

Formulae and casks here are generated by GoReleaser on release — do not edit
them by hand, your changes will be overwritten by the next tag.
